## IT Foundations Lecture
### Hardware and Storage
- CPU, memory, volatile/non-volatile data, storage and firmware; identify what survives a power loss.
### OS and Applications
- Kernel, process, thread, PID, service, application and update lifecycle. Show why a PID needs host and time context.
### Files and Paths
- Bytes, text encodings, newlines, extension versus content, file metadata and simple read/write permissions.
### Virtualization
- Host, guest, hypervisor, snapshot and backup; compare containers with guest operating systems and shared-kernel boundaries.
### Operations
- Inventory, ownership, dependencies and symptom-versus-cause troubleshooting.
